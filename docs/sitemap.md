# نقشه صفحات و مسیرها

## عمومی (بدون ورود)

| مسیر | صفحه | توضیح | ایندکس SEO |
| --- | --- | --- | --- |
| `/` | خانه | معرفی، خدمات، مراحل، اطلاعات لازم، مزیت‌ها، FAQ و مقالات منتخب | بله |
| `/services` | فهرست خدمات | کارت خدمات منتشرشده از CMS | بله |
| `/services/:slug` | جزئیات خدمت | متن، نکات، مدارک رایج و CTA | بله |
| `/clearance-process` | مراحل ترخیص | تایم‌لاین آموزشی ۷ مرحله‌ای | بله |
| `/documents-guide` | راهنمای مدارک | جست‌وجو و دسته‌بندی مدارک رایج | بله |
| `/articles` | مقالات | جست‌وجو، دسته‌بندی و صفحه‌بندی سمت سرور | بله |
| `/articles/:slug` | مقاله | متن، منبع و تاریخ بازبینی | بله |
| `/faq` | سؤالات متداول | آکاردئون پرسش‌های منتشرشده | بله |
| `/about` | درباره ما | معرفی و شفاف‌سازی موارد تأییدنشده | بله |
| `/contact` | تماس | فرم متصل به API + اطلاعات تأییدشده | بله |
| `/login` | ورود | نشست HttpOnly | خیر (`noindex`) |
| `/register` | ثبت‌نام مشتری | نقش همیشه `CUSTOMER` | خیر |

## مشتری (`CUSTOMER`)

| مسیر | صفحه | توضیح |
| --- | --- | --- |
| `/requests/new` | ثبت درخواست | فرم ۴ مرحله‌ای + بارگذاری اختیاری مدارک |
| `/dashboard` | پرونده‌های من | خلاصه وضعیت‌ها، فیلتر، جست‌وجو، صفحه‌بندی |
| `/dashboard/requests/:id` | جزئیات پرونده | تاریخچه، مدارک، پیام‌ها، بارگذاری تکمیلی، ثبت پیام |
| `/dashboard/profile` | مشخصات حساب | ویرایش نام و ایمیل |

## کارشناس (`EXPERT`) و مدیر (`ADMIN`)

| مسیر | نقش | توضیح |
| --- | --- | --- |
| `/admin` | کارشناس/مدیر | صف پرونده‌ها؛ کارشناس فقط پرونده‌های تخصیص‌یافته |
| `/admin/requests/:id` | کارشناس/مدیر | جزئیات، تغییر وضعیت، پیام و یادداشت؛ تخصیص و پیشنهاد برای هر دو نقش مجاز |
| `/admin/content` | مدیر | خدمات، مقالات، پرسش‌ها، پیام‌های تماس و تنظیمات |
| `/admin/users` | مدیر | نقش‌ها و فعال/غیرفعال کردن حساب |

## مسیرهای API

- پایه: `/api/v1`
- مستندات Swagger: `/api/docs`
- مشخصات JSON: `/api/docs/openapi.json`
- جزئیات قرارداد در [api-spec.md](./api-spec.md)

## صفحات خطا

- `*` → صفحه ۴۰۴
- دسترسی نقش نامناسب → پیام ۴۰۳ درون‌برنامه‌ای
- خطای API → پیام قابل‌فهم + امکان تلاش دوباره
